CKR Annotation Tools — Help

Align Tags (pick-driven) and the Annotation Dashboard (view-wide and automatic).

Align Tags

Procedure

  1. Select the tags / leadered text notes you want organised — a group, an area, or the whole view.
  2. Click the button to run with your last-used settings, or Shift+click to open the settings dialog.
  3. The selection is split into pipe bundles. Orange ring markers show the active group.
  4. Click where the bottom corner of that group's stack should sit. Click again to adjust; Esc moves to the next group.
  5. After the last group, overlaps between groups are resolved automatically. One Ctrl+Z reverts the cleanup; each pick is its own undo step.

What a "cluster" is

One physical pipe bundle: tags whose pipes run parallel (within 10°), sit side-by-side (within the Rack Width), and are tagged at the same station along the run (within Cluster Distance). Perpendicular pipes never share a stack; a long run tagged at several places gives one stack per place.

Leader shapes at Angle 0

SituationLeader
Tag level with a vertical pipeOne straight horizontal line; the elbow grip parks at its midpoint.
Tag must reach a horizontal pipeHorizontal landing, then a true 90° bend onto the pipe.
Tag must climb to a vertical pipeHorizontal landing, then a 7.5°-leaning climb (so the leader is never drawn along the pipe).

Any other angle (1–89°) gives classic parallel slanted leaders with straight landings.

Annotation Dashboard

A small always-on-top palette that applies the same leader rules without picking — and optionally to every new tag as you place it.

ControlWhat it does
Process VisibleApplies the leader rules to every supported tag visible in the active view — or just to your selection when something is selected. One undo step.
Dynamic TaggingWhile ticked, every newly placed tag gets the rules applied automatically the moment you create it.
Automatic Straight LeadersPrefer straight / L-bend shapes (equivalent to Angle 0).
AngleSlant used when straight leaders are off.
Landing DistanceHorizontal run from the text before the leader turns.
Elbow–Arrowhead DistanceMinimum distance kept between the bend and the arrow, so short leaders stay legible.
Attached End TagsAs in Align Tags: frees and pins attached arrowheads for exact geometry.
JustificationText-note justification to apply. Automatic judges each note on its own — justified towards the element it points at (Align Tags instead takes one direction for the whole stack).
Minimise / CloseClose also unhooks Dynamic Tagging.

Dynamic Tagging always opens off, even if it was on when you last closed the palette — reopening the tool can never silently start rewriting tags behind you.

Note: tags are never moved by the Dashboard — each keeps its position, only its leader is rebuilt. Use Align Tags when you want stacks arranged.

Reporting and troubleshooting

  • Tags without a leader or pinned are skipped and reported — tick "Leader" in Properties, or unpin, then rerun.
  • Settings live in %APPDATA%\CKR\tag_align_settings.json; a corrupt file falls back to defaults.
  • Every run logs to %APPDATA%\CKR\logs\align_tags.log and exports align_check.png of the result for review.
  • If a head lands more than 10 mm off-plan, the tool warns and names the tag in the log.
Undo model: every pick, the final arrangement, and each Dashboard action is exactly one undo step. Experiment freely.
